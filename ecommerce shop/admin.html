📬 Contact Form

Connect your contact form to Google Sheets so submissions are logged automatically.

How to set up (one-time):
1. Open sheets.new — create a blank spreadsheet
2. In the menu: Extensions → Apps Script
3. Delete all existing code and paste the script from the instructions
4. Click Deploy → New deployment → Web app
   • Execute as: Me  |  Who has access: Anyone
5. Copy the Web app URL and paste it below → Save & Publish
